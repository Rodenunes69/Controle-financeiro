CONTROLE FINANCEIRO - INSTALAÇÃO
=================================

ESTE É O ARQUIVO CORRETO PARA O GITHUB PAGES:
index.html

Envie TODOS estes arquivos para a raiz do repositório:
- index.html
- manifest.json
- sw.js
- icon-192.png
- icon-512.png
- README.txt

No GitHub:
1. Crie um repositório público.
2. Add file > Upload files.
3. Envie os arquivos acima.
4. Settings > Pages.
5. Source: Deploy from a branch.
6. Branch: main.
7. Folder: / (root).
8. Save.

Depois abra o endereço fornecido pelo GitHub Pages.

No Android, abra no Chrome e escolha:
Menu (⋮) > Adicionar à tela inicial / Instalar aplicativo.

IMPORTANTE:
Não renomeie index.html. Ele é a página inicial do aplicativo.
